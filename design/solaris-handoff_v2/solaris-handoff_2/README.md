# solaris-memory-assistent — pacote de handoff

Design aprovado: **Proposta A, "retrô calmo"**, paleta oficial **Estação** e logo **Reflexo A2**.

Comece por `HANDOFF.md`. Ele explica a ordem de leitura e o que vale em caso de conflito.

```
docs/Requisitos_v1.1.docx   requisitos funcionais e técnicos (seção 11 atualizada para este design)
HANDOFF.md                  telas, estados, componentes, comportamentos e critérios de aceite
design-tokens.json          cores das 5 paletas (claro e escuro), tipografia, espaçamentos, dimensões
referencia-png/             captura de cada tela (390 × 844, escala 2×) e das folhas de referência
telas/                      as mesmas telas em HTML estático, para abrir no navegador e medir
assets/                     logo, ícone do app, ícone de notificação, versão pixel e GIF da abertura
```

Todos os dados pessoais mostrados são fictícios.
